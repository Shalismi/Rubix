# Rubix interface fonts

These unmodified WOFF2 files are served locally so changing the interface font
does not require contacting an external font service.

- [Pilcrow Rounded](https://www.fontshare.com/fonts/pilcrow-rounded): variable
  normal face, weights 400–900. License: `pilcrow-rounded-FFL.txt`.
- [Nunito](https://github.com/google/fonts/tree/main/ofl/nunito): Latin variable
  normal face, weights 200–900, supplied by Google Fonts.
  The default interface font. License: `nunito-OFL.txt`.
- [Poppins](https://github.com/google/fonts/tree/main/ofl/poppins): Latin normal
  faces at weights 400, 600, 700, and 800, supplied by Google Fonts.
  License: `poppins-OFL.txt`.

Fontshare files and licenses were extracted from the official family downloads.
Google Fonts files were downloaded from the URLs supplied by its CSS API;
licenses are from the official Google Fonts repository. Retrieved October 25, 2026.
