The sidebar logo was prepared from the user's cube reference with the built-in
image generator in edit mode. Its background was removed, preserving the tile
colors, rounded shapes, angle, and glossy shading.

## Browser tab icon

[favicon.png](../../public/favicon.png) is a 32-pixel transparent cutout of the
user's cube-on-white-tile reference. [favicon.ico](../../public/favicon.ico)
contains 16-, 32-, and 48-pixel versions for browser tabs. These files are the
small, cropped exports of an edit made with the built-in imagegen tool.

Prompt:

> Use case: background-extraction. Asset type: Rubix browser-tab favicon. Input image: edit target, the user's attached cube on a white rounded tile. Remove the white tile, the surrounding white background, and its broad shadow. Preserve the exact cube, tile colors and arrangement, viewing angle, rounded edges, and glossy 3D shading. Center the complete cube on a square transparent canvas with only about 3% clear padding around it, so it fills the icon and remains legible at 16 and 32 pixels. No text, no new tiles, no additional objects. Do not redesign the cube.
